# 3D-skill

Claude Code uchun **hikoyali (storytelling) 3D veb-saytlar** yasaydigan skill — Awwwards darajasidagi saytlar (why.zero.university, palmo.co.in kabi) uslubida.

## Repo tuzilishi

```
3D-skill/
├── README.md                  ← shu fayl
├── PROGRESS.md                ← ⭐ ish jurnali: nima qilindi, hozir qayerdamiz, keyingi qadam
├── research/                  ← tadqiqot va tahlillar
│   ├── zero-university/
│   │   ├── story-analysis.md  ← sahnama-sahna hikoya tahlili (vaqtlar bilan)
│   │   ├── tech-analysis.md   ← texnik yechimlar (bulutlar, o'tishlar, optimizatsiya)
│   │   ├── review.md          ← kuchli/zaif tomonlar, baho
│   │   ├── frames/            ← kadr jadvallari (sheets/) va skrinshotlar (shots/) — README ichida
│   │   └── video/             ← to'liq yozuv (zero-960.mp4) + hodisalar vaqti (marks.json)
│   ├── other-sites.md         ← Palmo, Overworld Audio tahlili
│   ├── stack.md               ← tanlangan texnologiyalar va sabablari
│   └── analysis-method.md     ← saytlarni qanday tahlil qildik (qayta ishlatish uchun)
├── tools/
│   └── site-recorder/         ← saytni avtomatik videoga yozish skripti (puppeteer)
└── skill/                     ← skillning o'zi
    └── PLAN.md                ← skill tuzilishi rejasi
```

## Yangi agent uchun

Ishni davom ettirishdan oldin **`PROGRESS.md`** ni o'qing — unda to'liq holat, qarorlar va keyingi qadamlar bor.
